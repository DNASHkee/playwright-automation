🧪 Playwright – Automatizált szoftvertesztelés

📌 A projektről

Ez a repository az automatizált szoftvertesztelés tanulása és gyakorlása során készített projektjeimet tartalmazza.

Célom a tesztautomatizálási ismereteim fejlesztése, a különböző tesztelési technikák gyakorlati alkalmazása, valamint a megszerzett tudásom bemutatása.

A repository folyamatosan bővül az újonnan elsajátított technológiákkal, tesztelési módszerekkel és gyakorlati feladatokkal.

🛠 Technológiák

* Playwright
* JavaScript
* TypeScript (tervezett)
* Node.js
* Git / GitHub

🎯 Célkitűzések

* Automatizált tesztek tervezése és fejlesztése
* Különböző tesztelési módszerek gyakorlása
* Tesztkódok minőségének és karbantarthatóságának fejlesztése
* Új technológiák és eszközök megismerése
* Gyakorlati tapasztalatszerzés a szoftvertesztelés területén
